## Agent skills

Use GitHub Issues for specs, feature tickets, and bug reports. See [issue-tracker.md](docs/agents/issue-tracker.md).

Use the default Matt Pocock triage labels when classifying issues. See [triage-labels.md](docs/agents/triage-labels.md).

Use a single project glossary and ADR directory. See [domain.md](docs/agents/domain.md) when reading or recording project terminology and decisions.
